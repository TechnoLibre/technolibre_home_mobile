
# i18n de l'application

L'application utilise un système d'i18n léger et fait maison, dans `src/i18n/`. Aucune
bibliothèque externe — tout le code d'exécution tient en moins de 50 lignes de TypeScript.

## Vue d'ensemble de l'architecture

```
src/i18n/
├── index.ts   — runtime: getCurrentLocale(), setLocale(), t()
├── fr.ts      — French translations (source of truth / fallback)
└── en.ts      — English translations
```

Chaque fichier de langue exporte un unique enregistrement `translations` dont les clés
sont plates et séparées par des points :

```typescript
export const translations: Record<string, string> = {
    "nav.home": "Accueil",
    "label.font_size": "Taille de police — {size}",
    // …
};
```

`index.ts` importe les deux enregistrements dans une table `DICTS` indexée par `Locale`
(`"fr" | "en"`).

## Fonctionnement de `t()`

```typescript
t(key: string, params?: Record<string, string | number>): string
```

1. Lire la langue courante dans `localStorage` sous la clé `"app_lang"` (`"fr"` par défaut).
2. Chercher `key` dans le dictionnaire de cette langue.
3. Si absente : retomber sur le dictionnaire français, puis sur la chaîne de la clé
   elle-même, et émettre un `console.warn` pour que les clés manquantes se voient pendant
   le développement.
4. Substituer les paramètres nommés : chaque occurrence de `{nomParametre}` dans la chaîne
   résultante est remplacée par la valeur correspondante de `params`.

Exemple avec interpolation :

```typescript
t("label.font_size", { size: 16 })
// fr → "Taille de police — 16"
// en → "Font size — 16"

t("error.note_key_not_found", { label: "note" })
// fr → "Échec de la récupération des notes du stockage local."
// en → "Failed to retrieve notes from local storage."
```

Les paramètres sont remplacés avec `String.replaceAll` : un paramètre présent plusieurs
fois dans la même valeur est donc remplacé partout. `t()` ne lève jamais d'exception et ne
renvoie jamais `undefined`.

## Comment ajouter une clé de traduction

1. Ajouter la clé dans `src/i18n/fr.ts`, dans la section commentée adéquate :

   ```typescript
   // Ma section
   "ma_section.ma_cle": "Texte en français",
   ```

2. Ajouter la même clé dans `src/i18n/en.ts` :

   ```typescript
   // Ma section
   "ma_section.ma_cle": "English text",
   ```

3. Utiliser la clé dans un composant ou un service :

   ```typescript
   import { t } from "../../i18n";

   const label = t("ma_section.ma_cle");
   const interpole = t("ma_section.ma_cle_avec_param", { count: 3 });
   ```

Si la clé manque dans le fichier de la langue active, `t()` retombe sur la valeur
française et journalise un avertissement — elle n'affiche jamais `undefined` et ne lève
jamais d'exception.

## Comment ajouter une langue

1. Créer `src/i18n/xx.ts` (où `xx` est l'étiquette BCP-47, p. ex. `"es"`) avec
   l'enregistrement complet des traductions, en prenant `fr.ts` comme gabarit.

2. L'importer dans `src/i18n/index.ts` et étendre le type `Locale` et la table `DICTS` :

   ```typescript
   import { translations as es } from "./es";

   export type Locale = "fr" | "en" | "es";

   const DICTS: Record<Locale, Record<string, string>> = { fr, en, es };
   ```

3. Mettre à jour `getCurrentLocale()` pour accepter la nouvelle étiquette :

   ```typescript
   export function getCurrentLocale(): Locale {
       const stored = localStorage.getItem(STORAGE_KEY);
       if (stored === "en" || stored === "es") return stored;
       return "fr";
   }
   ```

4. Ajouter les clés de libellé du sélecteur dans `fr.ts` et `en.ts` :

   ```typescript
   "language.es": "Español",
   ```

5. Ajouter la nouvelle option au composant du sélecteur de langue
   (`src/components/options/options_language_component/`).

## Changement de langue à l'exécution

```typescript
import { getCurrentLocale, setLocale } from "../../i18n";

// Read the active locale (synchronous — reads localStorage)
const locale: Locale = getCurrentLocale();  // "fr" | "en"

// Switch locale — persists to localStorage then reloads the page
setLocale("en");
```

`setLocale` écrit dans `localStorage` puis appelle immédiatement
`window.location.reload()`. Ce rechargement complet est voulu : comme `t()` est appelée au
moment du rendu et non réactivement, un rechargement est le moyen le plus simple de
réafficher toutes les chaînes sans introduire un signal réactif global. La `STORAGE_KEY`
est `"app_lang"`. Toute valeur stockée autre que `"en"` retombe sur `"fr"`.

## Page Options › Langue

Le sélecteur de langue se trouve à :

```
Options › Langue
src/components/options/options_language_component/
```

Il présente deux choix via les clés `language.fr` (`Français (Canada)`) et `language.en`
(`English (Canada)`). Choisir l'un ou l'autre appelle `setLocale(locale)`, qui affiche une
courte note (`language.reload_note`) et déclenche le rechargement de la page.

La route est atteinte depuis le menu principal d'Options via l'entrée `options.language`.
